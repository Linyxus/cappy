scala3-py

Experimental Python backend for the Scala 3 compiler. This page hosts the Maven repository (maven/) and Coursier app channel (apps/) for published releases.

Install via Coursier

cs install --channel https://linyxus.github.io/scala3-py/apps scpyc

Resolver

To depend on a published artifact directly:

resolvers += "scala3-py" at "https://linyxus.github.io/scala3-py/maven"
